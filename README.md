### 💼 What I've Been Up To

- **Bytemith** (2024–2025)  
  Leading frontend efforts across multiple platforms, including digitalization of industrial processes and healthcare management tools. Delivered real-time interactive maps, dynamic form systems, and approval workflows using React, Chakra UI, Formik, and mapping integrations.

- **Quantum Boardgames** (2025)  
  Architected and developed an event management platform from scratch, including both frontend and backend. CI/CD pipelines with GitHub Actions, self-hosted infrastructure with Docker, NGINX, and Tailscale, deployed to a physical server and reverse proxy on Oracle Cloud.

- **Duna System** (2023–2024)  
  Frontend lead for a cutting-edge LiDAR 3D capture platform. Delivered authentication, permission systems, and CRUD features using React, Redux, MUI, Docker, and more. Also contributed to data architecture and business logic design.

- **Servit** (2019–2023)  
  Built over 30 responsive web interfaces for restaurant system integrations. Designed the admin system for reservation, menu, and table management. Tech stack included React, Redux Toolkit, Formik, Styled-Components, MUI, and SASS.
